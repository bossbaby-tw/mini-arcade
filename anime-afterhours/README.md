# Anime Afterhours — Character Club

A portrait guessing game featuring 47 characters across 12 universes: Naruto, Sanrio, Demon Slayer, Studio Ghibli, Ouran Host Club, Saiki K., Attack on Titan, Gintama, One Piece, Jujutsu Kaisen, Death Note, and Spy × Family.

## Run

Serve this folder with a static server and open the server URL. No dependencies or build step.

## Play

Select one or more universes, choose Portrait or Mystery mode, and start. Each session uses up to ten distinct characters. Answer with the four on-screen buttons or keys 1–4. H reveals the next hint; Enter advances after an answer. Best score is stored in the browser.

Portrait mode starts at 100 points, Mystery at 160. Each hint deducts 25 base points, with a minimum of 20 for a correct answer. Consecutive correct answers add 10 points per streak step, up to 50. Skips and incorrect answers break the streak. There is no timer.

## Artwork

Original character portraits are sourced from AniList character references and official Sanrio profiles. The in-game credits link to the source for every portrait. This is an unofficial fan quiz; characters and artwork belong to their respective rights holders. Fonts are loaded from Google Fonts, with system fallbacks. All gameplay assets are local; no live API is required.
