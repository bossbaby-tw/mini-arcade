# Mini Arcade

Quick browser games built with HTML, CSS, and JavaScript. No installation or build needed.

## Pocket Kart — Sunset Circuit

A three-lap arcade racer with four karts, golden boost pads, rechargeable boost, and touch controls.

[Play Pocket Kart](https://pocket-kart-sunset-1023.starryhorse7.chatgpt.site)

To play locally, download or clone this repository and open `pocket-kart/index.html` in a modern browser.

| Control | Action |
| --- | --- |
| Left / Right or A / D | Steer |
| Space | Boost |
| Down | Brake |
| P | Pause / resume |

Acceleration is automatic. Touch controls appear on touch screens.

## Add another game

Keep each game in its own folder. For example, upload the puzzle as `little-slide/index.html` and add its instructions here.
